## Organisation notes

- Backtracking has its own `BackTracking/` folder. `generateParentheses.py` and another `permutations.py` implementation still live in `DynamicProgramming/`.
- Some problems appear in multiple folders: Sort Colors in `Arrays&Hashing/` and `TwoPointers/`, Permutations in `BackTracking/` and `DynamicProgramming/`, and Design Circular Queue in `Queues/` and `LinkedList/`.
- `Stack/maxRectangleInHistogram.py` and `Stack/largestRectangleInHistogram.py` both implement Largest Rectangle in Histogram.
- Serialize and Deserialize Binary Tree is stored in `Stack/serializeAndDeserializeBinaryTree.py`.
- Solutions may contain multiple approaches, review notes, or judge-provided types/imports; the index records the files present rather than certifying every implementation as tested.
